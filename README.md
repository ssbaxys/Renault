# Renault — Чит-скрипт для Hypper Sandbox

**Renault** — это чит-скрипт, созданный на языке **Lua**, предназначенный для получения преимуществ над другими игроками в игре **Hypper Sandbox**.

> ⚠️ **Важно:** Использование читов нарушает правила игры и может привести к **постоянному бану** аккаунта.  
> Этот проект создан исключительно в **образовательных целях**. Используйте на свой страх и риск.

---

## 📋 Функционал

- **Player Modifications** — Изменение здоровья, скорости, прыжка и других параметров игрока.
- **Server Functions** — Прямое взаимодействие с серверными функциями.
- **Weapon Mods** — Клиентские изменения парметров оружия и так далее.
- **Skin Changer** — Смена скинов персонажей (включая пользовательские).
- **GG Script** — Полная совместимость с GameGuardian.

---

## ⚙️ Установка и Использование

Инструкции по установке отсутствуют в репозитории.  
Для использования скрипта требуются:

- **GameGuardian** (или совместимый скриптер).
- Загрузка скрипта через GG (`.lua` файлы из папки репозитория).

> 🔍 **Рекомендация:** Всегда проверяйте скрипты на вирусы перед запуском. Не доверяйте неизвестным источникам.
